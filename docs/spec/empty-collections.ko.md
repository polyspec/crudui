# 빈 반복 컬렉션

[English](empty-collections.md).

명시적인 빈 배열과 객체는 중첩 컬렉션을 포함한 반복 그룹과 단일 필드에서 행 0개를
생성합니다. 데이터가 없으면 초기 행을 생성합니다. React, Vue, Svelte는 각 빈
컬렉션 내부에 추가 버튼을 출력합니다. 버튼은 기존 `btn-plus` 동작 클래스를
사용하며 값을 제출하지 않습니다. 애플리케이션 컨트롤러는 버튼의 컬렉션에 신규
행을 삽입합니다. `design.show`는 행 개수와 별도로 표시 여부를 결정합니다.
컬렉션을 숨겨도 데이터를 유지하며 숨겨진 행의 이름 있는 컨트롤은 네이티브 제출에
포함합니다.

이 소스 수정은 행 생성과 빈 상태 출력만 변경합니다.
검증과 배포 상태는 [변경 기록](../../CHANGELOG.ko.md)에 기록합니다.
